## ✨ Features

- **🎨 Modern Design** - Professional, clean interface with distinctive typography
- **📱 Fully Responsive** - Optimized for all devices (mobile, tablet, desktop)
- **⚡ Fast Loading** - Pure HTML/CSS/JS with minimal dependencies
- **🎯 SEO Optimized** - Proper meta tags and semantic HTML structure
- **♿ Accessible** - WCAG compliant with keyboard navigation support
- **🌙 Smooth Animations** - Elegant scroll reveals and hover effects
- **📧 Contact Form** - Integrated contact form for client inquiries
- **🔝 Scroll to Top** - Convenient navigation button

## 🛠️ Built With

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with custom properties
- **JavaScript** - Vanilla JS for interactions
- **Font Awesome** - Icon library
- **Google Fonts** - Playfair Display & DM Sans typography

## 📋 Sections

The portfolio includes the following sections:

1. **Hero** - Eye-catching introduction with call-to-action
2. **About** - Personal story, journey, and professional values
3. **Services** - Offered services for potential clients
4. **Skills** - Technical expertise organized by category
5. **Projects** - Featured work with descriptions and links
6. **Education** - Academic background and certifications
7. **Contact** - Contact form and social links
8. **Footer** - Additional links and information
